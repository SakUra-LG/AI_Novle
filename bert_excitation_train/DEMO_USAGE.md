# Demo生成脚本使用说明

## 📝 功能说明

生成一个以**委屈情绪**为主题的demo内容，自动生成3个版本并选择评分最高的版本。

## 🚀 使用方法

```bash
python scripts/test_demo.py
```

## 📊 工作流程

1. **生成3个版本**
   - 每个版本使用略微不同的温度参数
   - 确保生成内容的多样性

2. **双重评分**
   - 规则评分：基于关键词和模式匹配
   - ML评分：基于机器学习模型（如果可用）
   - 综合评分：取两者平均值

3. **自动选择最佳版本**
   - 比较3个版本的评分
   - 选择评分最高的版本

4. **保存结果**
   - 最佳版本保存为文本文件
   - 所有版本保存为JSON文件

## 📁 输出文件

生成的文件保存在 `outputs/` 目录：

```
outputs/
├── demo_grievance_best_YYYYMMDD_HHMMSS.txt   # 最佳版本（文本）
└── demo_grievance_all_YYYYMMDD_HHMMSS.json   # 所有版本（JSON）
```

## 🎯 评分标准

- **目标评分**：≥85分
- **评分方式**：规则评分 + ML评分（如果可用）
- **评分范围**：20-100分

## ⚙️ 脚本特点

1. **独立运行**：不依赖任何现有小说上下文
2. **专门优化**：提示词针对"委屈"情绪和评分系统优化
3. **自动选择**：自动选择最高分版本
4. **详细输出**：显示每个版本的评分和内容

## 💡 提示词策略

为确保获得高评分，提示词包含：
- 强烈的冲突和误解场景
- 紧张的心理状态描写
- 高分关键词（如"紧张"、"心跳"、"逼近"等）
- 冲突场景（对峙、争论、被包围）
- 细腻的心理和生理反应

## ⚠️ 注意事项

1. **API配置**：确保API密钥正确配置
2. **评分模型**：ML评分需要训练数据，如果没有则仅使用规则评分
3. **生成时间**：每个版本生成需要30-60秒
4. **网络连接**：需要稳定的网络连接调用API
