# AI小说自动生成系统 - Web界面

## 概述

这是一个基于Web的AI小说自动生成系统界面，允许用户通过浏览器查看和管理现有的章节内容，以及生成新的章节。

## 功能特性

### 📚 章节管理
- **章节列表**：显示所有章节的状态和版本信息
- **内容查看**：点击章节可查看详细内容
- **版本切换**：支持查看同一章节的多个版本
- **实时更新**：自动检测文件变化并更新显示

### 🎛️ 控制面板
- **生成新章节**：启动AI生成新的章节内容
- **训练模型**：启动模型训练过程
- **查看统计**：显示系统运行统计信息
- **刷新数据**：手动刷新章节列表

### 🎨 用户界面
- **响应式设计**：支持桌面和移动设备
- **现代化UI**：美观的渐变色彩和动画效果
- **直观操作**：简单易用的交互界面
- **实时反馈**：操作状态和结果的即时显示

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动服务器

```bash
python start_web.py
```

或者直接运行：

```bash
python app.py
```

### 3. 访问界面

在浏览器中打开：http://localhost:5000

## 文件结构

```
项目根目录/
├── index.html          # 前端界面
├── app.py             # 后端API服务器
├── start_web.py       # 启动脚本
├── requirements.txt   # Python依赖
├── WEB_README.md      # Web界面说明
├── data/              # 数据目录
│   ├── chapters/      # 最终章节文件
│   └── candidates/    # 候选版本文件
└── outputs/           # 输出目录
```

## API接口

### 获取章节列表
```
GET /api/chapters
```

### 获取章节内容
```
GET /api/chapters/{chapter_id}
```

### 生成新章节
```
GET /api/generate/{chapter_id}
```

### 训练模型
```
GET /api/train
```

### 获取统计信息
```
GET /api/stats
```

## 使用说明

### 查看章节
1. 在左侧章节列表中点击要查看的章节
2. 右侧会显示章节内容
3. 如果有多个版本，可以点击版本标签切换

### 生成新章节
1. 选择要生成的章节
2. 点击"生成新章节"按钮
3. 系统会启动生成任务
4. 生成完成后会自动刷新列表

### 训练模型
1. 点击"训练模型"按钮
2. 系统会启动训练任务
3. 训练过程可能需要较长时间

### 查看统计
1. 点击"查看统计"按钮
2. 会显示系统的运行统计信息

## 配置说明

### 端口配置
默认端口：5000
修改端口：在 `app.py` 中修改 `app.run(port=5000)`

### 数据目录
- 章节文件：`data/chapters/`
- 候选文件：`data/candidates/`
- 输出文件：`outputs/`

### 文件命名规范
- 章节文件：`第X章.txt`
- 候选文件：`X_vY.txt`（X为章节号，Y为版本号）

## 故障排除

### 常见问题

1. **端口被占用**
   - 修改 `app.py` 中的端口号
   - 或者停止占用端口的程序

2. **依赖安装失败**
   - 检查Python版本（建议3.7+）
   - 使用虚拟环境：`python -m venv venv`

3. **文件无法读取**
   - 检查文件权限
   - 确保文件编码为UTF-8

4. **API请求失败**
   - 检查服务器是否正常运行
   - 查看浏览器控制台错误信息

### 调试模式

启动调试模式：
```bash
export FLASK_DEBUG=1
python app.py
```
