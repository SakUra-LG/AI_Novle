# 数据目录

该目录完整保留项目现有的情绪样本、通用 RAG 样本、人工标注集和训练集。

- 根目录 `*_samples.txt` 与 `*_examples.txt`：愤怒、委屈、恐惧、幽默、感动、复仇等样本。
- `universal_samples*`：通用样本原文、评分、结构化数据和向量。
- `labeled/`：训练、验证、测试和重评分表格。
- `training/`：人工标注、微调、DPO、LoRA 和增量训练数据。
- `pop_king_*.json`：第一份小说的人物、生命周期和风格约束。

不要批量去重或改写这些文件；它们同时承担原始样本、实验记录和模型训练输入的角色。
