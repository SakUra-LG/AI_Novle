# 📖 重生复仇小说正文生成器使用说明（`generate_chapter_content.py`）

本说明面向“用上下文 + RAG样本库 + 循环评分”来**按章节生成重生复仇小说正文**的使用场景。

---

## 你会用到哪些文件？

- **脚本**：`bert_excitation_train/scripts/generate_chapter_content.py`
- **章节梗概**（必需）：`bert_excitation_train/outputs/master_ctx.txt`
- **上一世线索**（可选，但强烈推荐）：`bert_excitation_train/outputs/prev_life_ctx.txt`
- **通用样本库**（RAG用，建议先初始化）：
  - `bert_excitation_train/data/universal_samples_data.json`
  - `bert_excitation_train/data/universal_samples_vectors.npy`

---

## 第 1 步：准备章节梗概（`outputs/master_ctx.txt`）

脚本会从每行中匹配 `第N章` 并读取冒号后的内容作为该章梗概。

示例：

```text
第1章 ：她被扔在ICU病房的地板上……：她全身插满管子，呼吸机发出尖锐的嗡鸣声……
第2章 ：她在病床上睁不开眼睛，却听见无数谩骂的声音……：网络直播平台不断弹出……
```

---

## 第 2 步：准备上一世线索（`outputs/prev_life_ctx.txt`）

脚本会从每行中匹配 `第N章对应线索` 并读取冒号后的内容作为该章“上一世回忆素材”。

示例：

```text
第1章对应线索：她记得在ICU病房的地板上，被推进抢救室时摔得头破血流……
第2章对应线索：她回想在病床上听到网上弹幕疯狂刷屏“烂货”、“自作孽不可活”……
```

> 提醒：如果这个文件缺失，脚本会给出提示并跳过“上一世回忆触发”，但正文仍可生成。

---

## 第 3 步（推荐）：初始化通用样本库（RAG）

如果你更新了 `data/universal_samples.txt`，请先运行一次样本处理脚本重建向量库：

```powershell
python .\bert_excitation_train\scripts\handle_universal_samples.py
```

---

## 第 4 步：生成某一章正文

### Windows PowerShell（推荐写法）

在 `AI_Novle` 目录下直接运行：

```powershell
python .\bert_excitation_train\scripts\generate_chapter_content.py --chapter 1
```

或进入 `bert_excitation_train` 再运行：

```powershell
cd .\bert_excitation_train
python .\scripts\generate_chapter_content.py --chapter 1
```

### 常用参数

- `--chapter`：章节号（必填）
- `--versions`：生成多个版本（默认 3）
- `--iterations`：每个版本的最大“情绪反馈优化”轮数（默认 3）
- `--min-emotion`：最低情绪强度阈值（默认 0.6）
- `--master-ctx`：章节梗概文件路径（默认 `outputs/master_ctx.txt`）
- `--prev-life-ctx`：上一世线索文件路径（默认 `outputs/prev_life_ctx.txt`）

---

## 输出在哪里？

生成完成后，最佳版本会写入：

- `bert_excitation_train/outputs/chapters/chapter_001.txt`
- `bert_excitation_train/outputs/chapters/chapter_002.txt`
- ...

---

## 常见问题（Troubleshooting）

### 1) PowerShell 报错：`FileNotFoundError: ... 'outputs/prev_life_ctx.txt'`

**典型原因**：用旧版脚本在 `scripts/` 目录运行时，相对路径会被解析成 `scripts/outputs/...`。

**解决方法**：

- 直接用本说明的命令运行（脚本已按 `bert_excitation_train/` 根目录解析 `outputs/...`）
- 或手动指定路径：

```powershell
python .\bert_excitation_train\scripts\generate_chapter_content.py --chapter 1 `
  --master-ctx .\bert_excitation_train\outputs\master_ctx.txt `
  --prev-life-ctx .\bert_excitation_train\outputs\prev_life_ctx.txt
```

### 2) 提示 `UNEXPECTED embeddings.position_ids`

这是加载某些 BERT/向量模型时常见的提示，一般**不影响运行**；只要后续不报错即可忽略。
