# V6 人工审查队列

> 用途：生成阶段只记录人工判断，不改动运行中的正式 JSON。待 250 个情节族 / 500 章章节卡全部产出后，按本队列逐项修改、全量校验并重新同步 Neo4j。

## 审查原则

- 重生复仇链必须可见：前世具体受害 → 今生独有信息差 → 主角主动布局 → 对方因轻视而入局 → 对方意识到是主角反击 → 现实损失/权力倒置 → 不可逆结算。
- 人物塑造必须落在选择上：同一性格根源同时形成优点与缺点；价值冲突必须触发动作、犹豫、撒谎、牺牲或关系变化，禁止用旁白直接解释性格。
- 关系变化写成可观察事实，不使用“绝对信任”“生死同盟”“命运共同体”“铁三角”等抽象结论代替剧情。
- 反派可以坏得滑稽，但滑稽行为必须推动其误判、露证或现实损失，不能只是插科打诨。

## 全量产出后的审查顺序

1. 先审每个事件的复仇债与结算闭环，优先修“主角未主动”“对方不知道是谁反击”“只有舆论评价而无现实损失”。
2. 再审主要人物的性格根、价值冲突、反常触发点和选择代价，消除抽象标签。
3. 检查同一反派的能力、资源、关系和法律状态是否与前序结算一致。
4. 修改正式事件与章节卡，运行全量校验，重新同步并核验 Neo4j，最后冻结正文依据文件。
