# 手动输入生成器使用说明

## 概述

这是一个简化的手动输入生成器，用户可以直接输入要求生成小说内容。

## 文件结构

```
├── scripts/
│   └── manual_generator.py       # 手动输入生成器
├── data/
│   └── universal_samples.txt     # 样本库（供参考）
├── outputs/                      # 生成的内容输出目录
└── 细节生成资料/                 # 现有的RAG系统（可选使用）
```

## 使用方法

### 1. 启动生成器

```bash
python scripts/manual_generator.py
```

### 2. 输入生成要求

系统会提示您输入生成要求，例如：
- "请写一段武侠对决的情节"
- "创作一个悬疑推理的场景"
- "写一段情感互动的内容"

### 3. 查看生成结果

系统会直接显示生成的内容，您可以选择是否保存到文件。

### 4. 退出程序

输入 `quit`、`exit` 或 `q` 退出程序。

## 功能特点

- ✅ **简单易用**：直接输入要求即可生成
- ✅ **手动控制**：完全由用户控制生成过程
- ✅ **质量保证**：内置武打场景特殊要求
- ✅ **文件保存**：可选择保存生成内容
- ✅ **持续使用**：支持连续生成多个内容

## 配置说明

如需修改API配置，请编辑 `scripts/manual_generator.py` 文件：

```python
API_Key_QW = "your_api_key_here"
MAX_TOKENS = 8192
```

## 样本参考

`data/universal_samples.txt` 文件包含高质量样本，您可以参考其中的写作风格和情节结构。

## 输出目录

生成的内容会保存在 `outputs/` 目录下，文件名格式为 `generated_YYYYMMDD_HHMMSS.txt`。

## 使用示例

```
请输入生成要求（输入 'quit' 退出）:
> 请写一段武侠对决的情节

======================================
生成结果:
======================================
拳风炸裂，两道刚猛劲力凌空相撞...
======================================

是否保存到文件？(y/n): y
请输入文件名（留空使用默认名称）: 武侠对决_章节24
内容已保存到: outputs/武侠对决_章节24.txt
```

## 注意事项

1. 确保网络连接正常，API可以正常调用
2. 生成内容可能需要一些时间，请耐心等待
3. 如果生成失败，请检查API密钥是否正确
4. 建议及时保存满意的生成内容
