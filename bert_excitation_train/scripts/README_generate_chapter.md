# 📖 重生复仇小说正文生成器使用说明

## 🎯 功能概述

本脚本用于生成重生复仇小说的正文内容，整合了项目的所有核心技术：

1. **样本集结构（RAG检索）**：从通用样本库中检索相似的高评分样本
2. **循环评分（情绪反馈循环）**：生成→评分→反馈→优化，最多迭代3次
3. **生成后评分**：规则评分 + 情绪分析双重评估
4. **回忆触发规则**：智能检测人物/地点/事件类型，只在触发时调用上一世回忆

## 🚀 快速开始

### 基本用法

```bash
# 生成第1章
python scripts/generate_chapter_content.py --chapter 1

# 生成第12章，生成3个版本，每个版本最多迭代3次
python scripts/generate_chapter_content.py --chapter 12 --versions 3 --iterations 3

# 自定义最小情绪强度
python scripts/generate_chapter_content.py --chapter 1 --min-emotion 0.7
```

### 参数说明

- `--chapter`: 章节号（必需）
- `--master-ctx`: 章节梗概文件路径（默认：`outputs/master_ctx.txt`）
- `--prev-life-ctx`: 上一世线索文件路径（默认：`outputs/prev_life_ctx.txt`）
- `--versions`: 生成版本数（默认：3）
- `--iterations`: 每版本最大迭代次数（默认：3）
- `--min-emotion`: 最小情绪强度阈值（默认：0.6）

## 📋 核心功能

### 1. 主线优先

- 正文必须严格按照本章章节梗概推进
- 不得偏离主线，不得新增重大剧情

### 2. 回忆触发规则（重点）

**触发条件**（满足任一即可）：
- 相同人物出现（如：林修远、赵明轩、陈主任等）
- 相同地点出现（如：ICU病房、公司、会议室等）
- 相同事件类型出现（如：陷害、嘲讽、裁员、拒绝、举报、开会等）

**调用流程**（固定格式）：
```
触发场景
  ↓
上一世具体失败回忆（50-150字）
  ↓
情绪变化（冷静、提前预判、不再犯错）
  ↓
今生提前布局或反击
```

**如果没有触发条件**：
- 禁止硬插回忆
- 否则正文会很乱

### 3. 风格要求（短剧节奏）

- 字数：800-1200字
- 每1000字至少1个情绪点或反转
- 对话占比高
- 情绪外显
- 结尾留悬念或冲突升级

### 4. 情绪强度保证

**使用的技术**：
1. **RAG检索**：从样本库中检索高评分样本作为参考
2. **循环评分**：生成后评分，如果情绪强度不足，自动优化
3. **情绪分析**：多维度情绪分析（强度、深度、转折、密度）
4. **综合评分**：规则评分 × 0.4 + 情绪强度 × 100 × 0.6

**情绪强度要求**：
- 目标：>= 0.6
- 多维度情绪：恐惧、紧张、期待、愤怒、悲伤、喜悦等
- 情绪深度：表层情绪 + 深层情绪（隐喻、转折、对比）
- 情绪转折：明显的情绪变化和波动
- 情绪密度：每100字至少2-3个情绪词汇

## 📊 生成流程

```
1. 加载章节梗概和上一世线索
   ↓
2. 检查回忆触发条件（人物/地点/事件类型）
   ↓
3. RAG检索相似样本（从通用样本库）
   ↓
4. 构建生成提示词（包含触发规则、RAG样本、情绪要求）
   ↓
5. 生成多个版本（默认3个）
   ↓
6. 对每个版本进行循环优化：
   - 生成内容
   - 规则评分
   - 情绪分析
   - 如果情绪强度不足，添加反馈并重新生成（最多3次）
   ↓
7. 选择最佳版本（综合评分最高）
   ↓
8. 保存到 outputs/chapters/chapter_XXX.txt
```

## 📁 输出文件

- **章节正文**：`outputs/chapters/chapter_001.txt`, `chapter_002.txt`, ...
- **自动保存**：每次生成后自动保存最佳版本

## 🔧 技术细节

### 使用的技术方法

1. **样本集结构（RAG检索）**
   - 使用 `smart_sample_search.py` 进行语义搜索
   - 从 `data/universal_samples.txt` 中检索相似样本
   - 自动适配样本内容到当前上下文

2. **循环评分（情绪反馈循环）**
   - 参考 `test_emotion_feedback_loop.py` 的实现
   - 生成→评分→反馈→优化，最多迭代3次
   - 每次迭代根据情绪分析结果添加针对性反馈

3. **生成后评分**
   - 规则评分：使用 `OptimizedRuleScorer`（20-100分）
   - 情绪分析：使用 `EmotionAnalyzer`（多维度情绪分析）
   - 综合评分：规则评分 × 0.4 + 情绪强度 × 100 × 0.6

4. **回忆触发规则**
   - 自动提取人物、地点、事件类型
   - 智能匹配触发条件
   - 只在触发时调用上一世回忆

### 情绪最大化技术

1. **RAG样本参考**：从高评分样本中学习情绪表达技巧
2. **循环优化**：如果情绪强度不足，自动添加反馈并重新生成
3. **多维度评估**：不仅评估情绪强度，还评估情绪深度、转折、密度
4. **综合评分选择**：选择综合评分最高的版本，确保情绪强度和质量平衡

## ⚠️ 注意事项

1. **确保上下文文件存在**：
   - `outputs/master_ctx.txt`（章节梗概）
   - `outputs/prev_life_ctx.txt`（上一世线索）

2. **RAG样本库**：
   - 确保已运行 `python scripts/handle_universal_samples.py` 初始化样本库
   - 样本库文件：`data/universal_samples_vectors.npy` 和 `data/universal_samples_data.json`

3. **API配置**：
   - 脚本中已配置通义千问API密钥
   - 如需修改，请编辑脚本中的 `API_Key_QW` 变量

4. **生成时间**：
   - 每个版本可能需要多次迭代
   - 生成时间取决于API响应速度和迭代次数
   - 建议在生成大量章节时使用批处理脚本

## 🔄 批处理生成

可以创建一个批处理脚本来生成所有章节：

```python
# batch_generate.py
from generate_chapter_content import RebirthRevengeGenerator

generator = RebirthRevengeGenerator()
generator.load_contexts('outputs/master_ctx.txt', 'outputs/prev_life_ctx.txt')

for chapter_num in range(1, 101):
    print(f"\n{'='*80}")
    print(f"生成第{chapter_num}章")
    generator.generate_chapter(chapter_num, num_versions=3, max_iterations=3)
```
