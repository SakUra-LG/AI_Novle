# V2 命令汇总

## `generate_event_clusters_v2.py`

| 命令 | 作用 |
|------|------|
| `python bert_excitation_train/scripts/generate_event_clusters_v2.py` | 生成全书大目标蓝图、事件簇列表；写出 `outputs/event_clusters_v2.json` 与时间戳副本 |

## `generate_outline_from_event_clusters_v2.py`

| 命令 | 作用 |
|------|------|
| `python bert_excitation_train/scripts/generate_outline_from_event_clusters_v2.py` | 读 `event_clusters_v2.json`，生成章节卡/梗概相关输出与稳定版 `outputs/prev_life_ctx_v2.txt` |

## `generate_chapter_content_v2.py`

| 命令 | 作用 |
|------|------|
| `python bert_excitation_train/scripts/generate_chapter_content_v2.py` | 按默认范围生成正文（见各参数默认值） |
| `python bert_excitation_train/scripts/generate_chapter_content_v2.py --prev-life <路径>` | 指定上一世线索文件（默认 `outputs/prev_life_ctx_v2.txt`） |
| `python bert_excitation_train/scripts/generate_chapter_content_v2.py --chapters-dir <路径>` | 指定章节输出目录（默认 `outputs/chapters_v2`） |
| `python bert_excitation_train/scripts/generate_chapter_content_v2.py --start <N>` | 起始章节号（默认 1） |
| `python bert_excitation_train/scripts/generate_chapter_content_v2.py --end <N>` | 结束章节号（默认 100） |
| `python bert_excitation_train/scripts/generate_chapter_content_v2.py --start 15 --end 16` | 只生成第 15～16 章 |
| `python bert_excitation_train/scripts/generate_chapter_content_v2.py --skip-neo4j-sync` | 生成后不同步 Neo4j |
| `python bert_excitation_train/scripts/generate_chapter_content_v2.py --neo4j-min-name-freq <N>` | Neo4j 构建时人名最小频次（默认 5） |
| `python bert_excitation_train/scripts/generate_chapter_content_v2.py --neo4j-auto-extract-relations` | Neo4j 构建时开启语义关系自动抽取 |
| `python bert_excitation_train/scripts/generate_chapter_content_v2.py --neo4j-reset` | 同步前清空 Neo4j 数据库（危险） |

## `generate_v2_pipeline.py`

| 命令 | 作用 |
|------|------|
| `python bert_excitation_train/scripts/generate_v2_pipeline.py` | 依次调用：事件簇 V2 → 大纲 V2 → 正文 V2 →（可选）Neo4j 构建 |
| `python bert_excitation_train/scripts/generate_v2_pipeline.py --project-config <路径>` | 指定 `project_configs.json` |
| `python bert_excitation_train/scripts/generate_v2_pipeline.py --generation-config <路径>` | 指定 `generation_config.json` |
| `python bert_excitation_train/scripts/generate_v2_pipeline.py --chapters <列表>` | 逗号分隔章节号，传给正文步骤（如 `1,2,3`） |
| `python bert_excitation_train/scripts/generate_v2_pipeline.py --workdir <路径>` | 工作目录（默认仓库根） |
| `python bert_excitation_train/scripts/generate_v2_pipeline.py --python <解释器>` | 指定 Python 可执行文件 |
| `python bert_excitation_train/scripts/generate_v2_pipeline.py --skip-clusters` | 跳过事件簇步骤 |
| `python bert_excitation_train/scripts/generate_v2_pipeline.py --skip-outline` | 跳过大纲步骤 |
| `python bert_excitation_train/scripts/generate_v2_pipeline.py --skip-chapters` | 跳过正文步骤 |
| `python bert_excitation_train/scripts/generate_v2_pipeline.py --skip-neo4j-build` | 跳过 Neo4j 从章节构建 |
| `python bert_excitation_train/scripts/generate_v2_pipeline.py --neo4j-reset` | Neo4j bootstrap 时加 `--reset`（危险） |

## `enhanced_rag_generator_v2.py`

| 命令 | 作用 |
|------|------|
| `python bert_excitation_train/scripts/enhanced_rag_generator_v2.py --chapter <N>` | 指定章节号（必填），增强 RAG 生成 |
| `python bert_excitation_train/scripts/enhanced_rag_generator_v2.py --chapter <N> --project <名>` | 项目名称（默认 `暗河噬城`） |
| `python bert_excitation_train/scripts/enhanced_rag_generator_v2.py --chapter <N> --prompt <文本>` | 额外生成提示 |
| `python bert_excitation_train/scripts/enhanced_rag_generator_v2.py --chapter <N> --versions <N>` | 生成版本数（默认 3） |
| `python bert_excitation_train/scripts/enhanced_rag_generator_v2.py --chapter <N> --min_score <分>` | 最低样本评分（默认 70） |
| `python bert_excitation_train/scripts/enhanced_rag_generator_v2.py --chapter <N> --min_emotion <0-1>` | 最低情绪强度（默认 0.6） |
| `python bert_excitation_train/scripts/enhanced_rag_generator_v2.py --chapter <N> --master_ctx <路径>` | 章节梗概文件 |
| `python bert_excitation_train/scripts/enhanced_rag_generator_v2.py --chapter <N> --prev_life_ctx <路径>` | 上一世线索文件 |

## Neo4j：`export_for_v2.py`

| 命令 | 作用 |
|------|------|
| `python -m bert_excitation_train.scripts.neo4j_kg.export_for_v2 --chapters <列表> --out <路径>` | 导出指定章节子图到 JSON（`--chapters` 逗号分隔） |
| `python -m bert_excitation_train.scripts.neo4j_kg.export_for_v2 ... --lookback <N>` | 在最小章节号前再包含 N 章 |
| `python -m bert_excitation_train.scripts.neo4j_kg.export_for_v2 ... --auto-anchors` | 自动补充早期锚点章节 |
| `python -m bert_excitation_train.scripts.neo4j_kg.export_for_v2 ... --max-auto-anchors <N>` | 限制自动锚点数量（默认 10） |

## Neo4j：`bootstrap_neo4j.py`

| 命令 | 作用 |
|------|------|
| `python -m bert_excitation_train.scripts.neo4j_kg.bootstrap_neo4j` | 创建约束/索引 |
| `python -m bert_excitation_train.scripts.neo4j_kg.bootstrap_neo4j --reset` | 清空库后重建（危险） |

## Neo4j：指定章节范围写入图数据库

| 命令 | 作用 |
|------|------|
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters --chapters 15-18` | 只根据第 15～18 章正文增量写入/更新 Neo4j（`outputs/chapters/chapter_*.txt`） |
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters --chapters 15,16,17` | 只处理所列章节 |
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters --start 15 --end 18` | 与 `--chapters 15-18` 等价，闭区间 |

## Neo4j：指定章节范围删除回溯（图 + 可选删文件）

| 命令 | 作用 |
|------|------|
| `python -m bert_excitation_train.scripts.neo4j_kg.delete_chapters_from_graph --chapters 15-18 --yes` | 从 Neo4j 删除这些章对应数据，并删除磁盘上对应 `chapter_*.txt` |
| `python -m bert_excitation_train.scripts.neo4j_kg.delete_chapters_from_graph --start 15 --end 18 --yes` | 同上，用起止章号指定范围 |
| `python -m bert_excitation_train.scripts.neo4j_kg.delete_chapters_from_graph --start 15 --end 18 --skip-file-delete --yes` | 只从 Neo4j 回溯删除，保留章节 txt |
| `python -m bert_excitation_train.scripts.neo4j_kg.delete_chapters_from_graph --chapters 15-18 --skip-neo4j-delete --yes` | 只删章节文件，不改 Neo4j |
| `python -m bert_excitation_train.scripts.neo4j_kg.delete_chapters_from_graph --chapters 15-18 --dry-run` | 预览将删章节与操作，不执行 |

## Neo4j：`build_from_chapters.py`

| 命令 | 作用 |
|------|------|
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters` | 从 `outputs/chapters` 下章节文本构建/更新 KG |
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters --min-name-freq <N>` | 人名最小频次（默认 5） |
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters --characters-config <路径>` | 角色配置文件 |
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters --relationships-config <路径>` | 关系配置文件 |
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters --candidates-out <路径>` | 候选人名审查 JSON 输出路径 |
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters --chapters <范围>` | 只构建指定章，如 `12-14` 或 `12,13,14` |
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters --start <N>` | 起始章（与 `--end` 或单独使用） |
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters --end <N>` | 结束章 |
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters --auto-extract-relations` | 开启语义关系抽取 |
| `python -m bert_excitation_train.scripts.neo4j_kg.build_from_chapters --min-promote-confidence <0-1>` | 关系提升为已确认的最小置信度（默认 0.8） |

## Neo4j：`delete_chapters_from_graph.py`

| 命令 | 作用 |
|------|------|
| `python -m bert_excitation_train.scripts.neo4j_kg.delete_chapters_from_graph --chapters <范围> --yes` | 从图中删除指定章节相关数据（需确认） |
| `python -m bert_excitation_train.scripts.neo4j_kg.delete_chapters_from_graph --chapters <范围> --skip-neo4j-delete` | 只删章节文件，不删 Neo4j |
| `python -m bert_excitation_train.scripts.neo4j_kg.delete_chapters_from_graph --chapters <范围> --skip-file-delete` | 只删 Neo4j，不删章节文件 |
| `python -m bert_excitation_train.scripts.neo4j_kg.delete_chapters_from_graph --chapters <范围> --dry-run` | 仅预览不执行 |

## Neo4j：`test_connection.py`

| 命令 | 作用 |
|------|------|
| `python -m bert_excitation_train.scripts.neo4j_kg.test_connection` | 测试 Neo4j 连接与最小查询 |
| `python -m bert_excitation_train.scripts.neo4j_kg.test_connection --query "<Cypher>"` | 自定义验证用 Cypher |
| `python -m bert_excitation_train.scripts.neo4j_kg.test_connection --retries <N>` | 重试次数（默认 3） |
| `python -m bert_excitation_train.scripts.neo4j_kg.test_connection --retry-wait-ms <N>` | 重试间隔毫秒（默认 1500） |
