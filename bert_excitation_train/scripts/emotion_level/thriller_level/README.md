# 恐惧强度五级样本生成

## 1. 如何调用使用

在项目根目录执行：

```powershell
python .\bert_excitation_train\scripts\emotion_level\thriller_level\run_thriller_levels.py
```

运行后会提示输入恐惧场景提示词：

```text
请输入恐惧场景提示词（直接回车使用默认场景）：
```

直接回车会使用默认场景：

```text
主角深夜独自回到老旧公寓，电梯停在不存在的十四层，监控屏里出现了另一个和自己一模一样的人。
```

脚本会自动生成恐惧强度 1~5 级片段，并输出到：

```text
bert_excitation_train/scripts/emotion_level/thriller_level/output/
```

每个等级会保存为一个单独的 `.txt` 文件。

## 2. 生成逻辑

恐惧分级强调“同一场景下的强度递增”，不靠单纯血腥或突然惊吓堆叠，而从以下维度控制：

1. 异常程度：等级越高，异常越具体、越无法用现实解释。
2. 空间压迫：等级越高，封闭、迷路、出口失效、楼层错位越明显。
3. 威胁逼近：等级越高，脚步、影子、门锁、监控、镜像、低语等线索越贴近人物。
4. 心理反应：人物从不安、警觉、惊惧逐步进入濒临崩溃但仍在求生的状态。
5. 收束方式：高等级需要清晰反转或不可回避的危机，避免血腥堆砌。

当前版本额外强调低级样本的“干净分界”：

1. 1级只允许轻微不安和可解释异常，不出现实体、对视、微笑、耳边呼吸或明确超自然证据。
2. 2级允许一次异常确认，但异常保持被动，不主动逼近、说话或切换成背后视角。
3. 3级开始出现回应、模仿、诱导等互动性威胁。
4. 4级重点写逃不出去、认知失效和身份替换风险，但避免直接肢体接触。
5. 5级可以稍长，增加恐怖环境描写，并落到失去身体、身份、记忆或现实位置等不可逆后果。

为保证五级样本可横向比较，脚本会额外执行场景一致性校验：

1. 每一级输出都必须命中输入场景中的关键锚点。
2. 如果输出出现医院、地铁、旅馆、停车场等非输入场景词，会被视为场景漂移并触发重试。
3. `horror_thriller_samples.txt` 会被解析为“样本库技法参考卡”，用于提供情绪标签、冲突结构、动作节奏、情节推进、评分和少量已屏蔽异场景词的技法摘录。
4. 样本会优先按“与当前场景锚点重合度 + 样本评分”排序接入，默认场景会优先选中老旧公寓、电梯、深夜等相关样本。
5. 五级样本接入数量按区间递增：1级 1~2 条，2级 3~5 条，3级 6~9 条，4级 10~13 条，5级 15~20 条；具体数量会结合样本库规模和该等级 `sample_ratio` 自动取值。
6. 生成 prompt 明确要求只学习样本的氛围密度、冲突结构和节奏，不得复制样本地点、人物、道具或事件。

## 3. 五级强度约束

核心规则定义在：

```text
thriller_level_generator.py
```

主要包括：

- `THRILLER_LEVEL_RULES`：五级恐惧强度的文字定义。
- `THRILLER_LEVEL_HARD_CONSTRAINTS`：每一级的可量化约束。
- `FEAR_CUE_WORDS`：恐惧心理和身体反应线索词。
- `THREAT_CUE_WORDS`：威胁逼近线索词。
- `SENSORY_CUE_WORDS`：声音、灯光、温度、影像等感官氛围线索词。
- `SPACE_CUE_WORDS`：电梯、走廊、门、楼层等空间压迫线索词。

生成后会自动统计：

- `fear_hits`：恐惧线索数量。
- `threat_hits`：威胁逼近线索数量。
- `sensory_hits`：感官氛围线索数量。
- `space_hits`：空间压迫线索数量。
- `dialogue_count`：对话数量。

如果某一级第一次生成不达标，脚本会把校验反馈加入 prompt 后重试，默认最多重试 3 次。

## 4. 样本来源

参考样本来自：

```text
bert_excitation_train/data/horror_thriller_samples.txt
```

不同等级会按比例注入不同数量的参考样本，高等级参考样本更多，用于增强惊悚密度、压迫节奏和收束质量。

## 5. API Key 要求

脚本优先读取环境变量：

```text
DASHSCOPE_API_KEY
```

如果环境变量不存在，会尝试从以下项目脚本读取 `API_Key_QW`：

```text
generate_chapter_content
manual_generator
emotion_guided_generator
```

如果两种方式都没有配置，会报错提示缺少 API Key。
